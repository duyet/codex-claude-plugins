# Commit and create PR

Follow `skills/commit-workflow/SKILL.md` in this plugin, including its pull request section.

Options: `--template <default|bugfix|feature>` overrides the template choice, `--draft` opens a draft PR, `--title` and `--body` override the generated ones.
