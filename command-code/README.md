# command-code

Install: `/plugin install command-code@duyet-claude-plugins`. Needs `cmd` authenticated (`cmd login`), `git`, and `gh` for issues.

- `command-code` skill: headless invocation and worktree dispatch rules.
- `/command-code:dispatch`: run tasks or issues as parallel workers.
- `cmd-dispatcher` agent: runs the dispatch loop.

`--yolo` removes the approval gate, so review every diff before merging.
