# Fix plugin

Find and fix failing tests, lint, type errors, and CI, then commit and push or open a PR.

## Install

```
/plugin install fix@duyet-claude-plugins
```

## What ships

- `/fix:and-push` - fix, commit, push
- `/fix:and-update-pr` - fix an existing PR and push
- `/fix:and-create-pr` - fix and open a new PR
- `fix-workflow` skill - the fixing loop all three share
