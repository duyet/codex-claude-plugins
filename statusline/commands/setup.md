# /statusline:setup

Follow the `statusline-workflow` skill (`skills/statusline-workflow/SKILL.md`).

1. Ask which preset to use (detailed, balanced, minimal, monitor, developer, performance) or custom. For custom, ask which sections to show, the context style, and the icon style.
2. Write `~/.claude/statusline.config.json`, set `statusLine` in `~/.claude/settings.json`, and show a preview.
