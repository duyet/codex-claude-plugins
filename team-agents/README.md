# team-agents

Install: `/plugin install team-agents@duyet-claude-plugins`

- Agents: `leader`, `senior-engineer`, `junior-engineer`, `deep-research-agent`, `performance-engineer`, `python-expert`.
- `/leader <task>`: run the leader with `--team-size`, `--mode`, `--quality`, `--dry-run`.
- Skills: `team-agents-workflow` (for harnesses without plugin agents), `task-decomposition`, `quality-gates`, `react-nextjs-patterns`, `backend-api-patterns`, `typescript-patterns`.

Fan-out mechanics live in the `orchestration` plugin.
