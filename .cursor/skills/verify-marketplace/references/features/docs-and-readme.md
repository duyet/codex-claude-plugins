# Docs and README

Install and contribution docs are how a human or agent learns the pack without
reading every manifest. Root README, CLAUDE.md, CONTRIBUTING.md, and per-plugin
README.md files are the user-visible docs surface.

## Sub-features

- `docs-claude-install` README includes marketplace add, plugin install,
  settings.json, and skills CLI.
- `docs-codex-install` README and CONTRIBUTING include
  `.agents/plugins/marketplace.json`.
- `docs-grok-install` README includes
  `grok plugin marketplace add duyet/codex-claude-plugins` and
  `.grok-plugin/marketplace.json`. CONTRIBUTING includes the Grok marketplace
  path.
- `docs-validate` CLAUDE.md and CONTRIBUTING tell contributors to run
  `scripts/validate-plugins.sh`.
- `docs-structure` CLAUDE.md names `.claude-plugin/plugin.json`,
  `.codex-plugin/plugin.json`, `.grok-plugin/plugin.json`, and
  `.grok-build-plugin/plugin.json`.
- `docs-plugin-readme` each plugin directory has `README.md` (warning unless
  `--strict`).

## How to get to it (user POV)

- Open `README.md` (Quick Install, Codex, Grok Build, Grok Bot, Manual
  Installation).
- Open `CLAUDE.md` (plugin metadata and validate command).
- Open `CONTRIBUTING.md` (new plugin checklist).
- Open `<plugin>/README.md` for plugin-specific usage.

## Driving it with control-marketplace

Preconditions:

- `control-marketplace doctor` reports `ok`.

- **Needles.** Run
  `node .cursor/skills/verify-marketplace/control-marketplace.mjs check-docs --json`.
  All checks without `severity: warn` pass.
- **Missing READMEs.** The `plugin-readmes` check lists names in `plugins`
  when README.md is absent. Record them; do not silently skip.
- **Strict mode.** Run
  `node .cursor/skills/verify-marketplace/control-marketplace.mjs check-docs --strict --json`
  when a change claims every plugin is documented. Exit 1 if any README is
  missing.
- **List filter.** Run
  `node .cursor/skills/verify-marketplace/control-marketplace.mjs list --missing-readme --json`
  to get the same names as an inventory.

## Gotchas

- The root README plugin table is generated by `scripts/plugins.py sync`
  between the `plugins:start` and `plugins:end` markers. Edit
  `marketplace.json`, not the table.
- `good-html` may lack `README.md` while still being a valid plugin. That is a
  docs gap, not a manifest gap.
- Do not scrape GitHub rendered README as proof; read the files in the
  checkout.
