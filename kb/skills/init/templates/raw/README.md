# raw

Input for the dream pass (`../DREAM.md`).

- `inbox/YYYY-MM-DD.md` holds rough captures as timestamped bullets with no frontmatter. The dream pass promotes durable facts into `../memory/` and deletes the processed file.
- Source docs placed directly in `raw/` (PDFs, articles, `llms.txt` snapshots) are read-only ground truth. Never edit them. Dream records each one in `.agent/state.json` under `processed` and keeps the file.

If this repo is public, keep only public material here.
