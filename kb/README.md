# kb

Install: `/plugin install kb@duyet-claude-plugins`

- `init` skill, `/init [path]`: scaffold a shared-brain folder (default `~/kb`) with an OKF `memory/` bundle, inbox, and CLI.
- `dream` skill, `/dream [path] [--auto]`, `/dream forget "<query>"`: consolidate a KB.

The scaffold vendors `render_okf_viewer.py`, identical to the one in `okf`. See `okf` for authoring and validation.
