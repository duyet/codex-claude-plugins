# Grok

- Prompt conversationally and directly. A short system prompt that sets tone is enough.
- It has live access to X and the web. Say the time window and the source type you want ("posts from the last 24 hours", "primary sources only") and ask it to cite them.
- It is willing on edgy or contested topics. Specify the register you want (neutral summary, devil's advocate, humor) so the personality does not choose for you.
- For factual claims, ask it to separate sourced facts from opinion and to flag low-confidence items.
- Use structured outputs or a stated schema for machine-readable results. Do not rely on style alone.
- Check the provider's model list for current ids, reasoning variants, and tool support.
