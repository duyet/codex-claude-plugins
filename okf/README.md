# okf

Install: `/plugin install okf@duyet-claude-plugins`

- `okf` skill: author, validate, and render Open Knowledge Format bundles. Ships `reference/SPEC.md`, `validate_okf.py`, and `render_okf_viewer.py`.
- `okf-refactor` skill: convert notes or catalog exports into a bundle.

Spec: [OKF v0.1](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md). The `kb` plugin vendors an identical `render_okf_viewer.py`.
