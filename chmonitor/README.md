# chmonitor

Skill for working on the ClickHouse Monitor dashboard: adding charts, pages, and query configs, calling its API, and writing version-aware system table queries.

## Install

```text
/plugin install chmonitor@duyet-claude-plugins
```

## What ships

- `skills/chmonitor/SKILL.md`: architecture, SWR patterns, chart and query-config recipes, compatibility rules.
- `references/api-list.md` and `references/api-endpoints.md`: chart and table endpoints.
- `references/dashboard-pages.md`: every dashboard page.
- `references/development.md`: routing, data fetching, multi-host setup, troubleshooting.
- `references/clickhouse-compat.md`: version-aware queries and optional tables.

Source project: <https://github.com/chmonitor/chmonitor>
