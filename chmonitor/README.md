# chmonitor

Agent skill and MCP server for [chmonitor](https://chmonitor.dev), the read-only ClickHouse dashboard and advisor.

```bash
/plugin install chmonitor@duyet-claude-plugins
```

Set `CHMONITOR_API_KEY` to a `chm_` key. Set `CHMONITOR_URL` to point at a self-hosted instance instead of `https://dash.chmonitor.dev`.
